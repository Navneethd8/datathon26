# GNN Dashboard

A comprehensive interactive dashboard for visualizing GNN-based accessibility hotspot detection results.

## Features

- **Overview**: Key statistics and project summary
- **Interactive Map**: Explore hotspots, barriers, and grid cells with multiple layer views
- **Hotspot Analysis**: Detailed analysis of detected hotspots
- **Baseline Comparison**: Compare GNN performance against 8 baseline methods
- **Model Architecture**: GNN model details and training information
- **Evaluation Metrics**: Comprehensive evaluation results

## Setup

1. **Generate Map Data** (if not already done):
   ```bash
   python generate_map_data.py
   ```
   This creates `outputs/map_data.json` from your GNN results.

2. **Start a Local Server**:
   ```bash
   # Python 3
   python -m http.server 8000
   
   # Or using Node.js
   npx http-server -p 8000
   ```

3. **Open Dashboard**:
   Navigate to `http://localhost:8000/dashboard.html` in your browser.

## Dashboard Sections

### Overview
- Key statistics: barriers, grid cells, hotspots, coverage, spatial coherence
- Project summary and key features
- Visualizations: embeddings, training curves

### Interactive Map
- **Barrier Points**: Individual accessibility barriers colored by severity
- **Grid Cells**: Spatial units with risk levels
- **Hotspots**: Detected high-risk hotspots
- **Heatmap**: Density visualization of barriers

### Hotspot Analysis
- Top high-risk hotspots with detailed metrics
- Risk scores, barrier counts, severity information

### Baseline Comparison
- Comparison table showing GNN vs. 8 baseline methods
- Metrics: hotspots detected, Jaccard similarity, spatial coherence
- Visual comparison charts

### Model Architecture
- GAT architecture details
- Training configuration
- Hotspot detection methodology

### Evaluation
- Comprehensive evaluation metrics
- Coverage analysis
- Spatial coherence (Moran's I)
- Clustering quality metrics

## Data Files

The dashboard loads data from:
- `outputs/map_data.json` - Map visualization data (generated by `generate_map_data.py`)
- `outputs/results.json` - GNN evaluation results
- `outputs/baseline_comparison.json` - Baseline comparison results
- `outputs/embeddings.png` - Embedding visualization
- `outputs/dashboards/training_curves.png` - Training progress
- `outputs/dashboards/evaluation_dashboard.png` - Evaluation dashboard
- `outputs/baseline_comparison/comparison_table.png` - Baseline comparison table
- `outputs/baseline_comparison/budget_coverage.png` - Budget vs coverage analysis

## Troubleshooting

**Dashboard not loading data:**
- Ensure you've run `generate_map_data.py` to create `map_data.json`
- Check browser console for errors
- Verify all JSON files exist in `outputs/` directory
- Make sure you're accessing via `http://localhost:8000` (not `file://`)

**Map not displaying:**
- Check that Leaflet library is loading (check browser console)
- Verify map data contains valid coordinates
- Ensure map container has proper height

**Missing images:**
- Images are optional - dashboard will work without them
- Check that image paths are correct relative to dashboard location
